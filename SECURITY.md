# Security

BRS Skill is an experimental validation framework.

Do not treat this repository as a certification mechanism for medical, legal,
financial, industrial, or other safety-critical use.

## Reporting a vulnerability

Please open a GitHub issue if the report can be public and contains no secrets,
private data, credentials, or exploit material that should remain confidential.

For sensitive reports, use a private contact channel configured by the repository
owner rather than posting secrets in a public issue.
